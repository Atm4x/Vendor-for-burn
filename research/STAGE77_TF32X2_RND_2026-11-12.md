# Stage 77 — Compensated TF32×2 RMVPE Conv2d
Parent: 8023de9999f7d31e9185802b991994037cb0fb8a. PR #2. Experimental CUDA-only feature; production defaults remain unchanged.

## Motivation
Stage75 RTX4060 full 89.94s audio: Direct RMVPE Conv2d 12.30s, ImplicitGemm 10.34s, but 3 voiced/unvoiced flips near salience threshold 0.03 produced PCM16 RMSE ~985.6. Stage76 diagnostic replacing only those three voiced decisions decreased PCM squared error by 99.864%; replacing complete reference F0 yielded identical WAV. That was a causal *test*, not a production solution.

Independent reconstructed PyTorch RMVPE with actual checkpoint and input preprocessing matched Direct's voiced decisions on problem chunks 005,014,027. CPU-modeled TF32 round-to-nearest of activations explained much of ImplicitGemm's discrepancy; two-component TF32 rounding recovered those decisions in numerical simulation. **This does not establish RTX performance or CUDA JIT correctness.**

## Source
`RVC_RMVPE_UNET_COMPENSATED_TF32=1` enables CUDA CubeCL split into high TF32-rounded activations plus residual and computes `Conv2d(high,W,bias)+Conv2d(low,W,None)`. The model weights, F0 threshold, NSF and other layers are unchanged. Ordinary RMVPE Direct remains default. All reference-F0 ablations remain diagnostic-only.

Local `cargo check --offline --locked -p tts-with-rvc-rs --no-default-features --features cuda --lib --bin tts-with-rvc-rs` passed in Rust 1.98.1 (type checking only). Actual GPU kernel/JIT, output quality and throughput are not yet verified. The second GEMM adds memory use and compute.

## Windows validation
CI `.github/workflows/rvc-stage77-tf32x2.yml` builds unified release EXE, checks PowerShell and bundled arithmetic unit test. Download `rvc-stage77-tf32x2-windows-x64` then run from the extracted folder with private assets in `embed`:

```cmd
powershell -ExecutionPolicy Bypass -File .\Run-RVC-Full-Stage77.ps1 -Device cuda -Voice ".\embed\CrazyMita.pth" -Hubert ".\embed\hubert_base.pt" -Rmvpe ".\embed\rmvpe.pt" -Index ".\embed\CrazyMita.index" -InputWav ".\embed\MitaKind.wav" -WarmRuns 2 -CoreFrames 300 -TensorBatchSize 2 -IndexRate 0.75 -Modes all
```

Output `RVC_STAGE77_FULL_WAV_RESULTS.zip`: baseline Direct, original ImplicitGemm, compensated TF32×2, full WAV timing, SHA256, PCM16 RMSE, error logs. CUDA Graph replay disabled. Never adopt a faster algorithm before actual listening and boundary-F0 parity across multiple recordings.
