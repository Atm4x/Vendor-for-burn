## Stage108 implementation

The existing Stage107 Single kernel is specialized at compile time for two weight layouts:

- **single**: original packed `[Cin, K, Cout/group]`, input NCT as a strided NTC view;
- **kic**: prepack static weights once from `[Cin, Cout/group, K]` to `[K, Cin, Cout/group]` so the inner Cin reduction walks contiguous weight vectors;
- **kic_ntc**: additionally materialize contiguous NTC input before convolution; this copy is included in measured operator latency.

The algorithm, tap order and FP32 accumulation remain unchanged. `#[comptime] weight_kic` removes the runtime format branch from the generated kernel. The optimization targets source/weight locality, not arithmetic complexity. The prior Pair and original Single remain unmodified and available.

Model integration is strictly opt-in: `RVC_NSF_POLYPHASE=1` and `RVC_NSF_POLYPHASE_KIC=1` (prepacked KIC) or `RVC_NSF_POLYPHASE_KIC=ntc` (extra contiguous NTC copy). Production default is untouched. Static weights are packed when the decoder loads, never per inference.
