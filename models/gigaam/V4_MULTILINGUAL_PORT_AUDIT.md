# GigaAM v4 / Multilingual v2: native Rust port audit (CONT01)

Baseline: Vendor-for-burn main `f3618c635442334f02c47384c01dd13fed1891f7`; upstream source archive GigaAM-main.zip, revision `e9bbf2e773eedd217c6f0d3b89b9728c41332b7d` (2026-11-27). Scope: native inference using Burn/CubeCL, not Python subprocesses, training or ONNX export. This is a static source audit, not official-checkpoint runtime parity. ## Architectural cutover

Use one loaded encoder per ASR model, with a typed encoder variant (Conformer or Zapformer), head collection (single or raw/e2e), optional language conditioner and independently owned stream state. Separate checkpoint identity, encoder geometry, head geometry, and worker capability. Reuse native weight reader, log-mel FFT, tokenizer implementation, LSTM math, service transport and device selection after parity checks; avoid duplicating the encoder for raw/e2e. Keep full-context and packet inference on the same parameter objects. Avoid full-utterance attention matrices where exact chunk masks permit bounded streaming caches. No new runtime dependencies are required by the source design; actual backend operator support must be tested.

## Acceptance gates

- G01-G03: resolve exact names and artifact inventories; test embedded metadata, wrong targets, stale sidecar precedence, tokenizer pairs and floating-point frontend against the new reference. Upstream `tests/test_loading.py`, `test_reading.py`.
- G04-G05: tiny deterministic Zapformer CPU FP32 tensors, uneven padded batch, per-stack outputs and length parity; `test_encoder_variants.py`. Then official checkpoints. Use explicit tolerance and record max error/RMSE/SNR, not just transcription text.
- G06-G07: independent head vocab sizes, blank/predictor behavior, shared encoder, raw/e2e outputs, auto/mixed/kz language vectors and FiLM placement; `test_language.py` and `test_batching.py`.
- G08: compare arbitrary packet splits and flush with whole chunk-mode inference for each supported context, including zero-length packets and two independent decoder states; `test_streaming.py`, `test_language.py`, `test_timestamps.py`.
- G09-G10: VAD short/empty/tail, hysteresis, minimum-probability split and segment timestamps; typed worker start/request/reset/shutdown; `test_longform.py` plus native worker contracts.
- G11: real checkpoint matrix plus legacy regression, warm GPU measurements; publish measured coverage per model/backend. Do not mark distribution support until the model passes the relevant gates.
