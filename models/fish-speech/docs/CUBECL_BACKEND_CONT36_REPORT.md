# Fish Speech CubeCL — CONT36 (2026-11-19)

## Scope and result

Continued the independent `Graph IR` CubeCL backend without touching the TensorRT implementation or the user's unpublished local fixes. Added seven model operations over the C01 baseline, with native 16-bit BF16 storage for KV tensors. **All operators from the current Transformer Graph IR now have a correctness-first CubeCL kernel**, but numerical execution and end-to-end generation remain unverified/unimplemented, respectively.

## Changes

- `TokenEmbedding`: I32 IDs to F32 token embeddings, contiguous vocabulary rows; check negative/out-of-range IDs before GPU submission.
- `FishEmbedding`: semantic membership LUT gating, shared versus independent codebook offsets, and only validate acoustic token IDs for semantic tokens that actually use acoustic embeddings.
- `SplitQkv`: packed BTD to Query/Key/Value BHTD with correct GQA head counts and packing offsets.
- `RoPe`: interleaved rotary using coefficients generated by the canonical `fish_rope_coefficients` (position and BF16-rounded trig); device-side elementwise rotation.
- `KvUpdate`: BF16 backing buffers, F32-to-BF16 round-to-nearest-even on writes and preservation of untouched cache entries.
- `KvPrefix`: copies the active BF16 prefix out of a capacity-backed cache; no future positions exposed.
- `GqaAttention`: F32 query, native BF16 K/V, right-aligned causal masking and GQA head mapping; correctness-oriented two-pass stable softmax. Scalar kernel is **not optimized**.
- Refactored the CubeCL implementation into `cubecl_backend/kernels.rs`, `runtime.rs`, and `tests.rs`; `cubecl_backend.rs` only exports the public API. No cross-backend code paths changed.
- BF16 input/output handles are 2 bytes per element; public CPU test bindings remain F32, explicitly encoded/decoded as BF16 at CubeCL boundaries. Check `bf16::supported_uses` before dispatch.
- Compile-time rejection of device-generated token IDs for the embedding operations until device-side error reporting exists. Invalid externally supplied token IDs and LUT gates are rejected before any launch.
- New compile/preflight tests and conditional CubeCL runtime parity tests (the latter require a functioning runtime, not available here).
